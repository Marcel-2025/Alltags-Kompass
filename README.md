# AlltagsKompass – Premium Landingpage

Responsive, komplett statische Landingpage für das geplante AlltagsKompass-App-Projekt.

## Start

`index.html` im Browser öffnen oder den gesamten Ordner auf GitHub Pages, Cloudflare Pages, Netlify o. Ä. hochladen. Keine Build-Tools, APIs, CDNs oder externen Fonts benötigt.

## Dateien
- `index.html`: Landingpage inkl. CSS und kleiner Demo-Interaktionen (Tabs, Checklisten, Mobile-Menü, Unternehmungskategorien, FAQ)
- `assets/alltagskompass-icon.svg`: editierbares randloses App-Icon (quadratisch, ohne Text)
- `assets/alltagskompass-icon.png`: App-Icon 1024×1024
- `assets/app-icon-512.png`: Google-Play-Größenreferenz 512×512
- `assets/app-icon-192.png`, `assets/app-icon-64.png`, `assets/app-icon-32.png`: weitere Exportgrößen
- `impressum.html`, `datenschutz.html`: **nur Entwürfe, vor Veröffentlichung vervollständigen**

## Vor Veröffentlichung unbedingt prüfen
1. Impressum mit realen Angaben vervollständigen und rechtlich prüfen.
2. Datenschutzhinweise passend zum tatsächlichen Hosting und allen eingebundenen Diensten finalisieren.
3. Bei tatsächlichem Release App-Downloads ergänzen; aktuell wird bewusst **keine fiktive Store-Verfügbarkeit** behauptet.
4. App-Funktionen als Produktversprechen nur beibehalten, wenn auch implementiert und getestet.
5. Echte App-Screenshots nach Vorliegen der Builds ergänzen.

## Markenstil
Deep Navy #071625, Petrol #112b3d, Mint #82e5cf, warmes Gold #f8c17d, Creme #f5f7f1. Das SVG ist quadratisch, randlos und ohne Text – bei nativen Plattformen die Maskierung vom Betriebssystem vornehmen lassen.
